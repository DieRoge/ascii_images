# 🎨 ASCII Wallpaper Generator

![C++](https://img.shields.io/badge/C%2B%2B-17%20%2F%2020-blue.svg)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)
![Dependencies](https://img.shields.io/badge/dependencies-zero%20(stb%20included)-brightgreen.svg)

Консольная утилита (CLI) на C++ для создания детализированных обоев в стиле ASCII-арт. В отличие от классических конвертеров, которые выводят текст в консоль, эта программа рендерит символы через настоящий `.ttf` шрифт прямо в `.png` изображение с сохранением исходного разрешения, пропорций и цветовой палитры.

---

## ✨ Возможности

* **Детекция границ (фильтр Собеля):** Автоматически находит контуры объектов на изображении и прорисовывает их направленными символами (`|`, `-`, `/`, `\`), делая картинку чёткой и выразительной.
* **Поддержка Юникода и псевдографики:** Внутренний движок работает с `UTF-32`, что позволяет рендерить не только базовый ASCII, но и блочную графику (`░▒▓█`), а также паттерны шрифта Брайля (`⠁⠃⠇⠏⠟⠿⣿`).
* **Гибкая цветокоррекция:** Настройка гаммы, контраста, усиления цвета (`color boost`) и инверсии яркостей прямо из командной строки — идеально для подгонки обоев под тёмную тему рабочего стола.
* **Мгновенный рендеринг:** Используется предварительное кэширование глифов (`Glyph Atlas`) и альфа-блендинг, благодаря чему генерация `FullHD` / `4K` обоев занимает доли секунды.
* **Всё включено:** Все необходимые зависимости (`stb`) уже находятся в репозитории — проект компилируется одной командой без установки сторонних библиотек.

## 📁 Структура репозитория

Все заголовочные файлы уже включены в проект, ничего докачивать отдельно не нужно:

```text
├── main.cpp               # Точка входа, CLI-парсер и подключение реализаций stb
├── ascii_renderer.hpp     # Ядро рендера: фильтр Собеля, кэш глифов, гамма-коррекция
├── stb_image.h            # Чтение изображений (JPG, PNG, BMP и др.)
├── stb_image_write.h      # Сохранение итогового холста в PNG
└── stb_truetype.h         # Растеризация векторных .ttf шрифтов
```

## 🚀 Быстрый старт (Сборка)

Для сборки понадобится любой современный C++ компилятор (`GCC`, `Clang` или `MSVC`) с поддержкой C++17 / C++20.

### 1. Клонирование репозитория
```bash
git clone https://github.com/DieRoge/ascii_images.git
cd <имя-репозитория>
```

### 2. Компиляция

**Через `g++` / `clang++` (Linux, macOS, MinGW / Git Bash на Windows):**
```bash
g++ -std=c++20 -O3 main.cpp -o ascii_wall
```

**Через CMake (опционально):**
```bash
mkdir build && cd build
cmake ..
cmake --build . --config Release
```

> 💡 **Примечание по шрифтам:** Для работы программе нужен любой моноширинный `.ttf` шрифт. Положите файл шрифта (например, `JetBrainsMono-Regular.ttf`, `DejaVuSansMono.ttf` или стандартный `consola.ttf` из `C:\Windows\Fonts`) в папку с программой или передайте путь к нему через флаг `-f`.

## 🛠 Использование

Базовый синтаксис запуска:
```bash
./ascii_wall -i <путь_к_картинке> -f <путь_к_шрифту.ttf> [опции]
```

### Параметры командной строки

| Флаг | Полное имя | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `-i` | `--input <path>` | Путь к исходному изображению (**обязательный параметр**) | — |
| `-o` | `--output <path>` | Имя или путь для сохранения результата в формате `.png` | `wallpaper_ascii.png` |
| `-f` | `--font <path>` | Путь к моноширинному `.ttf` шрифту | `font.ttf` |
| `-p` | `--preset <name>` | Выбор градиентного алфавита символов (см. таблицу ниже) | `standard` |
| `-s` | `--size <int>` | Высота одного символа в пикселях (меньше = выше детализация) | `18` |
| `-g` | `--gamma <float>` | Гамма-коррекция ($>1.0$ затемняет тени, $<1.0$ высветляет) | `1.0` |
| `-c` | `--contrast <float>` | Коэффициент контрастности изображения | `1.15` |
| `-t` | `--threshold <float>` | Порог срабатывания фильтра Собеля (меньше = больше контуров) | `0.28` |
| — | `--no-edges` | Отключить выделение границ контурными символами | выкл (границы активны) |
| — | `--mono` | Монохромный режим (зелёный текст в стиле ретро-терминала) | выкл (цветной режим) |
| — | `--invert` | Инвертировать яркость изображения | выкл |
| `-h` | `--help` | Показать справку по всем командам | — |

## 🔠 Доступные пресеты (`-p`)

Выбирай стиль отрисовки с помощью флага `-p <название>`:

| Пресет | Алфавит символов (от тёмного к светлому) | Рекомендация |
| :--- | :--- | :--- |
| `minimal` | ` .:-=+*#%@` | Отлично сочетается с контурами Собеля, чистый и стильный вид |
| `standard` | ` .'`^",:;Il!i><~+_-?][}{1)(|/tfjrxnuvcz...` | Плавные переходы за счёт большого количества символов (70 шт.) |
| `blocks` | ` ░▒▓█` | Плотная текстурная псевдографика (лучше запускать с `--no-edges`) |
| `hybrid` | ` .:-=+*#%@░▒▓█` | Комбинация классического ASCII в тенях и плотных блоков на свету |
| `braille` | ` ⠁⠃⠇⠏⠟⠿⣿` | Точечный матричный стиль (требует шрифт с поддержкой Брайля, например `DejaVuSansMono`) |
| `matrix` | ` .:+-*=%012345789Z#@&` | Киберпанк-эстетика (особенно круто смотрится с флагом `--mono`) |
| `binary` | ` 01` | Минималистичный бинарный стиль из нулей и единиц |
